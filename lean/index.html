Repository owner: gpartin

A selected linearized C19 lattice branch, its normalized long-wave spectral limit, and the Klein–Gordon differential equation for finite continuum mode sums.

Source / version
v0.7.0-research · commit fed494f8e9b9ad6b0c1f1b6afd2fda08072339df.

CSI independently rebuilt the pinned project (2,226 jobs, using the pinned Mathlib cache), ran the unmodified release verifier, and audited 176 public theorem constants covering all 53 explicitly named public source theorems on 17 November 2026. No physical-particle identification or experimental validation is established. External work; inclusion does not imply CSI affiliation or endorsement.
