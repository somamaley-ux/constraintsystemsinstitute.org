Read paperDownload PDFExact edition DOIWork DOI · all versions

Fixes interpreted context and complete required questions to derive the anchor, tensor and skin decomposition: context, answer profile and its realizations. Minimal complete encodings recover the same content space up to a unique commuting bijection.

What this edition establishes

The decomposition retains when each answer is available. Original descriptions are reconstructed over their context and complete content space without choosing a representative. Tensor names semantic content here; it need not be a physical tensor field.

Individual variations are classified even when one component performs several roles. The paper characterizes when partial comparison records determine the context and content partitions, and the least separate input information that finite joint constructions require.

For sequential operators it distinguishes deciding authorization, recovering a successful result and reporting rejection. A complete code must preserve each original use and its applicability, rather than only a final verdict.

About this paper and citation
Imports
States a one-way order: Kernel, AMetric, Structure, fixed-domain exhaustion, then ATS. References name kernel v49, AMetric editorial reference, Structure examples reference 20 September and Exhaustion composition reference 20 September.
Supplies downstream
Supplies a typed organization for assembling/checking admissible descriptions and certificates. It does not serve as a premise for the earlier general exhaustion theorem.
Scope and limits
A complete semantic profile is not merely an admissibility bit and need not identify a unique occupant. Minimal-realization uniqueness does not imply uniqueness among every adequate realization. Sequential substitution requires joint original-domain factorization; a licence alone is not execution.
