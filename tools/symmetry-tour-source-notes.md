## Interactions

1. **Transformation bench.** A unit vector initially at 30 degrees in an illustrative Euclidean plane. Passive mode turns the basis and transforms coordinates by the inverse rotation while the represented point remains fixed. Active mode rotates the point in the fixed basis. The displayed radius remains one in both modes; this alone is not a certificate of complete physical equivalence. Sources: SYM-0 §§3.4–4.3; public SYM-2 §§5.2–5.3 and §§6.2–6.4 (PDF18–19).
2. **Abelian gauge loop.** Four local frame phases, with `a'_ij = a_ij + theta_i - theta_j`. The oriented edge sum telescopes, and `W = exp(i Phi)` is unchanged by frame changes. An independent loop-phase control changes the physical invariant modulo a full turn. This is a U(1) teaching model on the proper-bulk locus, not a non-Abelian field solver. Sources: SYM-1 §6.2, §§7.1–7.4, Theorem10.2 and §§11.2–11.3.
3. **Anomaly ledger.** One left-handed Standard Model generation, with SU(3) cubic, SU(3)^2Y, SU(2)^2Y, Y^3 and gravity^2Y coefficients plus SU(2) weak-doublet parity. Exact source table: SYM-3 Table14.1, PDF117 / printed105. Aggregate result: Chapter17 / T19, PDF63–64. Global parity: Chapter18 §18.1 / T20, PDF65. The zero-hypercharge doublet counterexample is in §17.3. Omitting e^c is an original illustration directly calculated from the source table, not claimed to be the paper's particular negative-control example. Passing these tests does not construct the interacting quantum theory.
4. **Operator constraints.** Stipulated nonzero representative sectors with transfer rows d5=(0,2), d6=(1,1), d7=(1,-1). Each imposes `DeltaB alphaB + DeltaL alphaL = 0`. The remaining continuous total-B/L phase subspace has dimension2,1,0. Coefficient support is explicit: a dimension cutoff does not automatically enable a term. Discrete remnants and electroweak topology remain separate. Source: SYM-7 §6, Tables9–13 (PDF20–23), Theorems6.1–6.7 (PDF24).
